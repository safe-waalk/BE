# 서울 도보망 데이터 적재 (pgRouting) 설계

- **작성일**: 2026-07-19
- **관련 문서**: `docs/superpowers/specs/2026-07-19-safety-score-design.md`
- **상태**: 승인됨

## 배경 / 목적

안전 가중치 최단경로 계산(pgRouting)을 하려면, 도보 가능한 도로망이 그래프(노드+엣지) 형태로 DB에 있어야 한다. 카카오모빌리티/티맵 같은 외부 길찾기 API를 호출해서 경로를 받아온 뒤 점수만 매기는 방식도 검토했지만, 그러면 "외부가 골라준 경로의 안전도"만 알 수 있을 뿐 "가장 안전한 경로 자체를 계산"할 수는 없다. pgRouting(PostGIS 확장, Supabase 기본 지원)을 쓰면 엣지 비용에 안전점수를 반영해 실제로 더 안전한 경로를 계산해낼 수 있고, 외부 API 신청/승인 절차나 별도 라우팅 서버(OSRM) 운영도 필요 없다.

이 스펙은 그 전제 조건인 **서울 지역 OSM 도보 가능 도로망을 Supabase(PostGIS)에 그래프로 적재**하는 것까지만 다룬다. 안전점수를 엣지 비용에 반영해 실제 경로를 계산하는 API는 이 데이터가 준비된 이후 별도 스펙에서 다룬다. 이 작업은 Spring Boot 애플리케이션 코드가 아니라 1회성 데이터 적재 절차다.

## 범위

**포함**:
- 서울 지역 OSM 도보 가능 도로망을 pgRouting 그래프 테이블(`ways`, `ways_vertices_pgr`)로 적재
- 샘플 `pgr_dijkstra` 쿼리로 그래프가 정상 동작하는지 검증

**제외 (YAGNI)**:
- 전국 확장 — 이번 파이프라인이 검증된 뒤 별도 작업으로 진행
- 정교한 보행자 인프라 필터링(인도 유무 등 세밀한 태그 기반 선별) — 자동차 전용도로만 제외하는 기본 설정으로 시작하고, 실제 경로 품질을 보면서 나중에 튜닝
- 안전점수를 엣지 비용에 반영하는 로직 — 다음 스펙(안전 가중치 경로 API)에서 다룸
- `cctv` 테이블의 한국 밖 이상치 좌표 56건 정리 — 이번 작업과 무관한 별도 이슈

## 데이터 소스 및 처리 절차

1. Geofabrik(`download.geofabrik.de`)에서 대한민국 OSM 추출본(`.osm.pbf`) 다운로드
2. `osmium extract`로 서울 bounding box만 잘라냄 — 기존 CCTV/보안등 테스트에 쓰던 좌표들(예: 위도 37.42~37.70, 경도 126.76~127.18 범위, 서울 시계 기준)이 포함되도록 클리핑
3. Supabase 대시보드 또는 SQL로 `postgis`(이미 활성화됨), `pgrouting` 확장 활성화
4. `osm2pgrouting` 도구로 클리핑된 데이터를 Supabase에 적재
   - 필터링: 기본 설정 사용 — 고속도로/자동차 전용도로만 제외, 나머지(일반도로, 인도, 보행자전용길 등)는 전부 도보 가능으로 취급
   - 결과 테이블: `ways`(엣지 — `LineString` geometry, `source`/`target`/`length_m`/`cost`/`reverse_cost` 등 pgRouting 표준 컬럼), `ways_vertices_pgr`(노드 — `Point` geometry)
   - 테이블명은 `osm2pgrouting`/pgRouting 튜토리얼의 기본 명명 규칙을 그대로 따른다 (도구 호환성 우선, 이 프로젝트의 다른 테이블처럼 도메인 이름으로 바꾸지 않음)

## 검증

- `ways`/`ways_vertices_pgr`의 row 수가 서울 지역 도로망 규모에 합리적인지 확인 (극단적으로 적으면 클리핑 범위가 잘못된 것)
- 서울 시내 두 지점(예: 기존 테스트 좌표인 종로구 인근)에서 각각 가장 가까운 노드를 찾아 `pgr_dijkstra`로 최단경로를 계산해보고, 경로가 비어있지 않고 두 지점을 실제로 연결하는지 눈으로 확인

## 미해결 / 향후 과제 (이번 범위 아님)

- 전국 확장
- 인도/보행자 인프라 기반 정교한 필터링
- 안전점수를 경로 비용에 반영하는 로직 (다음 스펙: 안전 가중치 경로 API)
- `cctv` 테이블 이상치 좌표 정리
